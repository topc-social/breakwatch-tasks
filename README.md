# Breakwatch tasks

Breakwatch's public project repo: tasks and the Neki ledger for Breakwatch. When an API you depend on ships a breaking change, Breakwatch finds the code it breaks in your repo and opens a pull request that fixes it, tested before you see it. Dependabot, but for the APIs you call. First up: Shopify, Stripe, OpenAI and Anthropic.

- [Issues](https://github.com/topc-social/breakwatch-tasks/issues): open tasks. Each issue is one task, and its `neki:N` label is the Neki it earns (1 Neki = 1 rupee of work at market price).
- [`LEDGER.md`](LEDGER.md): who has earned what. Your share of Breakwatch = your Neki / all Neki there.

## How it works

1. Pick any open issue. Anyone can hand in, and the best hand-in wins.
2. Do the work however you like, including with your own AI.
3. Hand in by commenting on the issue with a link others can open (usually a pull request on the code repo) and a line or two on what you did.
4. Kamal accepts the best hand-in, labels the issue `accepted`, and closes it. A workflow then adds the two Neki rows (1% idea, 99% work) to [`LEDGER.md`](LEDGER.md) itself.

## Rules

- Proof must be something others can open, and anyone you quote or record has to agree to it.
- Made-up people, answers or numbers earn nothing.
- Neki is a record of your work and becomes your share in what gets built. Rules: TOPC's NEKI.md.
